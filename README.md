# benitez.studio

Static website for Benitez Studio (Frankie Benitez), hosted on GitHub Pages at https://benitez.studio.

- `index.html`: home (performance gallery)
- `about/`: about, training, video
- `contact/`: contact form (opens the visitor's email app)
- `assets/`: CSS, JS, images
- `CNAME`: custom domain for GitHub Pages
